
# Hotel Booking QA Testing

End-to-end Software Quality Assurance project.

## Project Overview

This project focuses on testing a hotel booking
web application using manual and automated
software testing techniques.

## Application Under Test

https://automationintesting.online/

## Tools and Technologies

- Jira - Project and defect management
- Postman - REST API testing
- Selenium WebDriver - UI test automation
- Python & Pytest - Automated test execution
- Git & GitHub - Version control

## Test Scope

- Functional testing
- Manual testing
- REST API testing
- UI test automation
- Defect reporting
