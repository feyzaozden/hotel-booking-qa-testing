
# Hotel Booking System - QA Test Plan

**Project:** Hotel Booking QA Testing
**Jira Task:** HBQA-6
**Status:** Draft
**Version:** 1.0
**Date:** 2026-10-08

## 1. Objective

The objective of this project is to evaluate
the functionality and reliability of a hotel
booking application through manual testing,
REST API testing, and UI test automation.

## 2. Application Under Test

Application: Restful Booker Platform
URL: https://automationintesting.online/

## 3. Test Scope

### In Scope
- Room availability and booking workflow
- Reservation form validation
- Date selection functionality
- REST API response validation
- UI automation of selected user journeys

### Out of Scope
- Performance and load testing
- Penetration testing
- Cross-browser compatibility testing
- Mobile application testing

## 4. Test Approach

### Manual Testing
Functional, positive, negative, and
exploratory testing.

### API Testing
REST API testing using Postman, including
status codes, response bodies, and
negative test scenarios.

### UI Automation
Browser automation using Selenium WebDriver,
Python, and Pytest.

## 5. Test Environment

- Operating System: Windows
- Browser: Google Chrome
- Test Management: Jira
- API Testing: Postman
- Automation: Python, Selenium, Pytest
- Version Control: Git and GitHub

## 6. Entry Criteria

- Test environment is accessible.
- Main application features are identified.
- Test scenarios are prepared.

## 7. Exit Criteria

- Planned tests are executed or marked blocked.
- Test results are documented.
- Identified defects are recorded in Jira.
- Critical defects are reviewed and reported.

## 8. Deliverables

- QA test plan
- Manual test cases
- Postman API collection
- Selenium automation scripts
- Defect reports
- Test execution summary

## 9. Risks

- Test environment availability
- Shared test data changes
- Limited project execution time
- Unstable browser or network connections
